# Studium AI

Osobní studijní repozitář pro poznávání umělé inteligence a sledování vývoje v oboru. Zahrnuje teorii, modely, nástroje, vývoj aplikací, praktické experimenty i širší souvislosti.

Komunikace a obsah poznámek jsou v češtině. Názvy adresářů a souborů jsou vždy v angličtině.

Podstatné poznatky z konverzací se průběžně ukládají jako strukturované poznámky v Markdownu. Nové a aktualizované zápisy se automaticky commitují do Gitu a ihned po každém commitu se provádí push do vzdáleného repozitáře.
